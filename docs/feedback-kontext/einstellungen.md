# Einstellungen
**Zweck:** Persönliche App-Konfiguration — Profil, Erscheinungsbild, KI-Anbindung, Speicher, Tags, Tastatur. Jeder User pflegt hier seine eigenen Einstellungen (kein Kurator-Bereich).
**UI-Elemente & Begriffe:** Tabs „Profil" (Name/Kürzel/Avatar, Kurator-Login-Panel), „Meine Technologien" (Kompetenz-Selbstauskunft für Auslastung), „Darstellung" (Primärfarbe-Presets, Dark-Mode-Toggle, Live-Vorschau), „Speicher" (IndexedDB/Daten-Share-Status), „Dokumentenquellen", „Tags" (Tag-Verwaltung mit Umbenennen/Löschen/Neu-zählen), „Tastatur" (Shortcuts). Zusätzlich je nach Build/Feature-Flag: „KI-Assistent" (Provider-Auswahl: OpenRouter/Intern/Cloud/Streamlit Bridge, Kontextlänge, Thinking-Toggle), „Online" (zuletzt aktive Team-User).
**Datenmodell dahinter:** `useProfile`-Hook (Profil inkl. `theme.hue`/`theme.dark`), `useMAIdentity` (Session-Kürzel im MA-Login-Modus), `useTags`-Hook (Tag-Zählung über `vorgang:`/`doc:`-IDB-Keys), AI-Provider-Config im `idb`-Store unter Key `ai-provider` (`AIProviderConfig`).
**Typische Aktionen:** Name/Kürzel/Avatar ändern; Primärfarbe wechseln, Dark Mode umschalten; KI-Provider/Modell/Endpoint konfigurieren; Kurator-Modus aktivieren (Passwort); Tags umbenennen/löschen; eigene Technologien/Kompetenzen pflegen (Auslastung).
**Code:** `src/plugins/einstellungen/` — Hauptdateien: `index.ts` (Plugin-Registrierung), `EinstellungenPage.tsx` (Tab-Orchestrierung), `ProfilTab.tsx`, `AIProviderTab.tsx`, `TagsTab.tsx`.
