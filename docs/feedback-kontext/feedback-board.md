# Feedback
**Zweck:** Öffentliche Übersicht aller gemeldeten Probleme, Ideen und Lob: Fortschritt verfolgen, per Stimme („Ich auch") Nachfrage zeigen, kommentieren und Ideen/UX mit einem Punkte-Budget sponsern (priorisieren).
**UI-Elemente & Begriffe:** Kopf mit Titel „Feedback", Zählern (Probleme/Ideen/Lob), Benachrichtigungs-Glocke (ungelesene Team-Antworten → springt zu „Von mir") + Budget-Badge „Budget Q3 · N/10 Pkt". Scope-Segmente „Alle / Von mir / Vom Team", Suchfeld, Sortier-Dropdown (5 Ordnungen, u.a. Meiste Punkte / Kurz vor dem Ziel / Meiste Sponsoren), Umschalter Liste/Board. Typ-Filter-Chips „Alle · Problem · Idee · UX · Lob · Frage" + Status-Filter (Liste). In „Von mir" eine „Dein Fortschritt"-Leiste. **Liste:** Karten mit Typ-Icon, Titel (+ „Antwort"-Marker bei neuer Team-Antwort), einer Vorschauzeile, Status-Pill, Mini-Fortschritts-Stepper (eigene), Bereich, Autor, Aufwand, Kommentar-Zähler; rechts Sponsoring-Leiste „X/Y Pkt · N Sponsoren" (Ideen/UX mit Aufwand) oder Vote-Pill + optionales Screenshot-Thumbnail (Lightbox); eigenes Feedback mit Akzentstrich links. **Board:** Kanban-Spalten nach Status (Neu · Geplant · In Bearbeitung · Umgesetzt · Abgelehnt) + eigene Lob-Spalte; leere Spalten klappen zusammen. Klick öffnet den Detail-Drawer: voller Fortschritts-Stepper, alle Antworten, Downloads, „Antwort vom Team" (ungelesen rot + „Neu"), Sponsoring-Panel (X/Y Pkt, +/−-Vergabe, Budget-Hinweis), Kommentar-Thread + Vote. Feedback *geben* liegt auf dem globalen Button unten rechts (optionaler Titel + Datei-Anhänge).
**Datenmodell dahinter:** `FeedbackItem` (title, category, kurator_status, context.page, effort_estimate, votes[], comments[], sponsors[], kurator_response); Titel notfalls aus der Hauptantwort abgeleitet; Votes/Kommentare team-geteilt (Merge + Outbox), getrennt vom Sponsoring. Stepper aus `kurator_status` abgeleitet (kein Verlauf); Ungelesen-Status gerätelokal.
**Typische Aktionen:** filtern, sortieren, Ansicht wechseln, eigenen Fortschritt/Antworten verfolgen, stimmen/zurückziehen, kommentieren, Idee/UX sponsern (+/−), Detail öffnen, neues Feedback über den globalen Button melden.
**Code:** `plugins/feedback-board/FeedbackBoardPage.tsx`; Komponenten `components/feedback/` (`FeedbackCard`, `FeedbackKanban`, `FeedbackBoardDetail`, `FeedbackStepper`/`FeedbackMiniStepper`, `FeedbackSponsorBar`/`FeedbackSponsorPanel`, `NotificationBell`, `MyProgressBar`, `FeedbackVotePill`, `SponsorButton`); Service `core/services/feedback/`.
