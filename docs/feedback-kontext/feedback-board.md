# Feedback
**Zweck:** Öffentliche Übersicht, in der alle Nutzer gemeldete Probleme, Ideen und Lob einsehen, per Stimme („Ich auch") die Nachfrage zeigen, kommentieren und Ideen/UX-Vorschläge mit einem persönlichen Punkte-Budget sponsern können, um sie zu priorisieren.
**UI-Elemente & Begriffe:** Kopf mit Titel „Feedback", Zählern (Probleme/Ideen/Lob) + Punkte-Budget-Badge. Toolbar: Scope-Tabs „Alle / Von mir / Vom Team" (mit Zählern), Suchfeld „Feedback durchsuchen", Sortier-Umschalter (Neueste zuerst ↔ Meiste Votes), Ansicht-Umschalter Liste/Board. Typ-Filter-Chips „Alle · Problem · Idee · UX · Lob · Frage" (mit Zählern + Farb-Punkt, aktiv gefüllt). **Liste:** scannbare Karten mit Typ-Icon, Titel, kompakten Frage/Antwort-Zeilen, Status-Badge, Bereich-Chip, Autor (Avatar+Name), Kommentar-Zähler, Vote-Pill (Daumen-hoch + Zahl) und optionalem Screenshot-Thumbnail (Klick = Lightbox); eigenes Feedback trägt einen Akzentstrich links. **Board:** Kanban-Spalten nach Status (Neu · Geplant · In Bearbeitung · Umgesetzt · Abgelehnt) + eigene Lob-Spalte, kompakte Karten. Klick auf eine Karte öffnet rechts einen Detail-Drawer (Titel, Autor, alle Antworten, Screenshot, Datei-Downloads, „Antwort vom Team", Kommentar-Thread mit Eingabe, Sponsoring-Block für Ideen/UX, Vote-Button im Fuß). Feedback *geben* liegt auf dem globalen Button unten rechts (dort optionaler Titel + Datei-Anhänge: PDF/Word/Excel/PowerPoint/CSV/TXT/MD).
**Datenmodell dahinter:** `FeedbackItem` (title, category, kurator_status, context.page, effort_estimate, votes[], comments[], sponsors[], kurator_response); Titel notfalls aus der Hauptantwort abgeleitet; Votes/Kommentare team-geteilt (Merge + Outbox), getrennt vom Sponsoring.
**Typische Aktionen:** nach Sicht/Typ/Suche filtern, sortieren, Ansicht wechseln (Liste/Board), eigenes Feedback am Akzent erkennen, für ein Feedback stimmen (Vote) oder Stimme zurückziehen, kommentieren, Idee/UX sponsern, Ticket-Detail öffnen und Verlauf/Antwort lesen, neues Feedback über den globalen Feedback-Button melden.
**Code:** `plugins/feedback-board/FeedbackBoardPage.tsx`; geteilte Komponenten in `components/feedback/` (`FeedbackCard`, `FeedbackKanban`, `FeedbackBoardDetail`, `FeedbackTypeChips`, `FeedbackVotePill`, `FeedbackCommentThread`, `FeedbackAvatar`, `SponsorButton`); Service `core/services/feedback/` (`feedbackVoting.ts`, `feedbackComments.ts`, `feedbackSponsoring.ts`).
