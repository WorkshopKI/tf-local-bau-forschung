# Feedback
**Zweck:** Öffentliche Übersicht, in der alle Nutzer gemeldete Bugs und Feature-Ideen einsehen und Ideen/UX-Vorschläge mit einem persönlichen Punkte-Budget sponsern können, um sie zu priorisieren.
**UI-Elemente & Begriffe:** Header mit Bug-/Feature-Zähler + Budget-Badge, Sponsoring-Info-Banner, Filter-Chips (Sicht: Alle/Mein Feedback — nur bei gesetztem Profilnamen; Status: Alle/Offen/Umgesetzt, Kategorie: Bug/Idee/UX/Lob/Frage, Bereich), drei Ansichten umschaltbar (Split = Liste+Detail, Kartenansicht gruppiert nach Kategorie, Listenansicht/Tabelle), pro Karte/Zeile: Status-Badge, Kategorie, Aufwand-Schätzung (S/M/L/XL), Sponsoring-Fortschrittsbalken + Sponsor-Buttons (Punkte 1/2/3/5 oder Stunden-Dialog). Das eigene Feedback (user_id == Profilname) ist hervorgehoben (Akzent-Rand + „Dein Feedback"-Badge, in der Tabelle „Du"-Chip), damit man den Bearbeitungs-Status der eigenen Tickets wiederfindet. Erreichbar aus der Sidebar-Fußzeile über das Feedback-Übersicht-Icon; Feedback *geben* liegt auf dem globalen FAB unten rechts.
**Datenmodell dahinter:** `FeedbackItem` (category, kurator_status, context.page, effort_estimate, Sponsoring-Einträge) aus `feedbackService`; `FeedbackConfig` (Schwellen/Budget) aus `loadFeedbackConfig`; Sponsoring-Fortschritt via `getSponsoringProgress`.
**Typische Aktionen:** Feedback filtern (Sicht „Mein Feedback"/Status/Kategorie/Bereich), eigene Tickets am Akzent + „Dein Feedback"-Badge erkennen und ihren Status verfolgen, Ansicht wechseln (Split/Karten/Liste), Idee/UX-Vorschlag sponsern oder Sponsoring zurückziehen, Ticket-Detail öffnen und Verlauf/Notizen lesen, neues Feedback über den globalen Feedback-Button (FAB) melden.
**Code:** `plugins/feedback-board/FeedbackBoardPage.tsx` (Seite, 3 Ansichten); geteilte Board-Komponenten in `components/feedback/` (`FeedbackBoardCard.tsx`, `SponsorButton.tsx`); Service-Layer `core/services/feedback/` (`feedbackService.ts`: `sponsorTicket`/`unsponsorTicket`/`getSponsoringProgress`).
