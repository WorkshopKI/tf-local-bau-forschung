# Feedback
**Zweck:** Öffentliche Übersicht aller gemeldeten Probleme, Ideen und Lob: Fortschritt verfolgen, per Stimme („Ich auch") Nachfrage zeigen, kommentieren und Ideen mit einem Punkte-Budget sponsern (priorisieren).
**UI-Elemente & Begriffe:** Kopf mit Titel „Feedback", Zählern (Probleme/Ideen), Benachrichtigungs-Glocke (ungelesene Team-Antworten → springt zu „Von mir") + Budget-Badge „Budget Q3 · N/10 Pkt". Scope-Segmente „Alle / Von mir / Vom Team", Suchfeld, Sortier-Dropdown (5 Ordnungen), Umschalter Board (Standard)/Liste + Dichte-Knopf (Komfort/Kompakt, gerätelokal gemerkt). Typ-Filter-Chips „Alle · Problem · Idee · Lob · Frage" + Status-Filter (Liste). In „Von mir" eine „Dein Fortschritt"-Leiste. **Liste:** Karten mit Typ-Icon, Titel (+ „Antwort"-Marker bei neuer Team-Antwort), Vorschauzeile (kompakt: einzeilig), Status-Pill, Mini-Stepper (eigene), Bereich, Autor, Aufwand, Kommentare; rechts Sponsoring-Leiste „X/Y Pkt · N Sponsoren" (Ideen mit Aufwand) oder Vote-Pill + Screenshot-Thumbnail (Lightbox); eigenes Feedback mit Akzentstrich. **Board:** farbige Kanban-Spalten mit Status-Symbol (Neu · Abgelehnt · Geplant · In Bearbeitung · Umgesetzt); Lob hat keinen Workflow und erscheint nur in der Liste; leere Spalten klappen zusammen. Board-Karten: Typ-Farbkante + Typ-Label, Datum, Titel, optionales Vorschaubild, unten Autor („Du" bei eigenen) + Datei-/Kommentar-Zähler + Punkte bzw. Vote-Pill. Klick öffnet das Detail-Panel rechts: voller Stepper, alle Antworten, Downloads, „Antwort vom Team" (ungelesen rot + „Neu"), Sponsoring-Panel (X/Y Pkt, +/−, Budget-Hinweis), Kommentar-Thread + Vote. Feedback *geben* liegt auf dem globalen Button unten rechts (optionaler Titel + Datei-Anhänge).
**Datenmodell dahinter:** `FeedbackItem` (title, category, kurator_status, context.page, effort_estimate, votes[], comments[], sponsors[], kurator_response); Titel notfalls aus der Hauptantwort abgeleitet; Votes/Kommentare team-geteilt (Merge + Outbox), getrennt vom Sponsoring. Stepper aus `kurator_status` abgeleitet (kein Verlauf); Ungelesen-Status gerätelokal.
**Typische Aktionen:** filtern, sortieren, Ansicht/Dichte wechseln, Fortschritt/Antworten verfolgen, stimmen, kommentieren, Idee sponsern, Detail öffnen, neues Feedback melden.
**Code:** `plugins/feedback-board/FeedbackBoardPage.tsx`; Komponenten `components/feedback/` (`FeedbackCard`, `FeedbackKanban`, `FeedbackBoardDetail`, Stepper/SponsorBar/VotePill u.a.); Service `core/services/feedback/`.
