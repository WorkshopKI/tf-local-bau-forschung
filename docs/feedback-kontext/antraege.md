# Förderanträge
**Zweck:** Zentrale Arbeitsseite für Förderanträge (Master-Detail) — Anträge suchen/filtern, Details ansehen und bearbeiten, Status/Dokumente/Klassifikation verwalten.
**UI-Elemente & Begriffe:** Liste links (`AntraegeMain`/`AntraegeTable`, sortier-/gruppierbar, Such-Header); bei offenem Detail schrumpft sie auf eine schmale, **nach Verbund gruppierte** Kompakt-Spalte (`KompaktListe`, ein Eintrag je Verbund). Detail rechts (`VerbundDetail`): Kopf mit Titel + Eckdaten-Meta hinter dem FKZ + Workflow-Stepper, darunter **Kurzbeschreibungs-Karte**, Gutachten-Werkstatt und kollabierte Sektionen „Antragsdaten" / „Verbundpartner und Teilvorhaben" (`TvDetailBlock`) / „Alle Felder" / „Historie". Filter als drittes Panel (`FilterSidebar`/`FilterDrawer`), Eckdaten-Editor (`EckdatenCard`), Klassifikations-Pills, Netzwerk-/Cluster-Karte. Verbund (mehrere Teilvorhaben) oder Solo/Pseudo-Verbund; FKZ `16KN######`/`16EP######`.
**Datenmodell dahinter:** `useAntraegeStore` (Zustand, CSV-Schema `Antrag`/`Verbund`/`AntragListItem` aus `core/services/csv/types`), Hybrid-Suche (`useAntraegeHybridSearch`, Orama BM25+Vector), Filter-State im Store, Feld-Historie, Dokument-Tags im `kv`-Store (u.a. Gutachten-Kurzfassung, Nachforderungen).
**Gutachten-Werkstatt (falls Feature aktiv):** Entwurf-Karte (`SectionReviewCard`) + rechtes „Quelle & Prüfung"-Panel (`KontextPanel`). „Antragsbezug" listet Zitate als **Beleg-Karten** (Hover verbindet Zitat↔Satz, Klick springt hin) + Abdeckungs-Zähler. Prüfpanel zeigt Regel-Checks nach Schweregrad — grüner Haken (ok), amber Punkt (Hinweis), rote **Fehler-Karte** mit Messwert/Limit; je Fehler ein KI-Korrektur-Knopf, bei Stil-Befunden ein „Anzeigen"-Link zum Satz. Kopf: „{f} Fehler · {h} Hinweise". Offline: Checks/Bearbeiten möglich, KI-Knöpfe deaktiviert.
**Typische Aktionen:** Antrag suchen/filtern (Status, Bearbeiter, Programm); Antrag/Verbund öffnen und Eckdaten einsehen/bearbeiten; Status nachverfolgen; Dokumente prüfen; Klassifikation setzen; bei Verbund zwischen Teilvorhaben wechseln; Gutachten-Kurzfassung anstoßen + Fehler per KI-Knopf korrigieren / Fundstelle „Anzeigen" (Verbund-Ebene, falls Feature aktiv); Filter-Panel ein-/ausklappen.
**Code:** `src/plugins/antraege/` — Hauptdateien: `AntraegePage.tsx` (Layout-Orchestrierung), `AntraegeMain.tsx`/`AntraegeTable.tsx` (Liste), `VerbundDetail.tsx` (Detail: Verbund + Teilvorhaben), `store.ts` (Zustand-Store), `filter/FilterSidebar.tsx`.
