# Förderanträge
**Zweck:** Zentrale Arbeitsseite für Förderanträge (Master-Detail) — Anträge suchen/filtern, bearbeiten, Status/Dokumente verwalten.
**UI-Elemente & Begriffe:** Liste links (`AntraegeMain`/`AntraegeTable`, sortier-/gruppierbar, Such-Header); bei offenem Detail schrumpft sie zur **Kompakt-Spalte** (`KompaktListe`, ein Eintrag je Verbund). Detail rechts (`VerbundDetail`): Kopf (Titel + Meta + Workflow-Stepper), **Kurzbeschreibungs-Karte**, Gutachten-Werkstatt, kollabierte Sektionen „Antragsdaten" / „Verbundpartner und Teilvorhaben" / „Alle Felder" / „Historie". Offenes Teilvorhaben (`TvDetailBlock`): Felder, Netzwerk, Dokumente; Titel markierbar + per Icon kopierbar. Filter als drittes Panel (`FilterSidebar`); Eckdaten nur ohne Verbund. Verbund (mehrere TV) oder Solo/Pseudo-Verbund; FKZ `16KN######`/`16EP######`.
**Datenmodell dahinter:** `useAntraegeStore` (Zustand, CSV-Schema `Antrag`/`Verbund`/`AntragListItem`), Hybrid-Suche (`useAntraegeHybridSearch`, Orama BM25+Vector), Filter-State, Feld-Historie, Dokument-Tags im `kv`-Store (u.a. Kurzfassung, Nachforderungen).
**Gutachten-Werkstatt (falls Feature aktiv):** Oben **„Dokumente des Verbundes"** (`KorpusInventar`): alle Dateien mit Typ + Umfang. Die maßgebliche **Vorhabensbeschreibung** ist markiert; jedes weitere Dokument hat „ins Gutachten aufnehmen" — nicht aufgenommene gehen nicht an die KI. Erneuter Upload ersetzt die Fassung; Altbestand ist als „ältere Fassung" markiert. Darunter die Entwurf-Karte (`SectionReviewCard`): „**prüft N Regeln**" klappt die **Regelprüfung** auf (Umfang/Sprache/Struktur, Messwert/Limit + KI-Korrektur) — zu bei grüner Prüfung, offen bei Hinweis/Fehler. Anpassen-Zeile: Neu/Kürzer/Länger schreiben aus der VB neu; abgesetzt daneben **„Sprachlicher Feinschliff"** (Lektor: nur Sprache, Inhalt/Umfang bleiben; Vorfassung im Versionsvergleich, Zahlen-/Längen-Abweichung wird gemeldet). Rechts „Quelle & KI-Hinweise" (`KontextPanel`): **Beleg-Karten** (Klick → Satz), Abdeckung, KI-QS. Offline: Bearbeiten/Prüfen ja, KI-Knöpfe aus.
**Typische Aktionen:** Antrag suchen/filtern (Status, Bearbeiter, Programm); Verbund öffnen; zwischen Teilvorhaben wechseln; TV-Titel kopieren; Dokumente hochladen + Gutachten-Kontext wählen; Abschnitt erzeugen, per KI korrigieren, sprachlich glätten.
**Code:** `src/plugins/antraege/` — `AntraegePage.tsx` (Layout), `AntraegeMain.tsx`/`AntraegeTable.tsx` (Liste), `VerbundDetail.tsx` (Detail), `store.ts`, `filter/FilterSidebar.tsx`.
