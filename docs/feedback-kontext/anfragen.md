# Anfragen
**Zweck:** Kurze E-Mail-Anfragen (Outlook `.msg`) DSGVO-sicher extern per KI beantworten lassen — intern anonymisieren, extern beantworten, Antwort automatisch mit Originaldaten wieder befüllen.
**UI-Elemente & Begriffe:** Fünf-Status-Pipeline „aufgenommen → anonymisiert → export_freigegeben → antwort_importiert → finalisiert". Aufnahme-Ansicht (.msg-Import — direkt danach automatisches internes KI-Tagging). Tabellenansicht: sortier-/filterbar; die getaggten Metadaten (Art/Thema/Firma) sind Spalten-Filter. Detail-Kopf: Metadaten-Streifen (Art/Thema/Firma/Name + Status, „(Erneut) taggen"). Anonymisierungs-Ansicht (Original-Mailtext links editierbar — Anrede/irritierenden Text vor dem Anonymisieren entfernen; anonymer Text rechts editierbar, Export-Guard, „Kopieren" zum externen ZIM-FAQ-Assistenten). Der kopierte Text erhält eine Präambel: Anrede ans Team ignorieren, nur die Fragen beantworten, Antwort-Mail an den Absender, alle Platzhalter unverändert erhalten. Original nach dem Anonymisieren geändert → anonyme Fassung veraltet (Export gesperrt bis Re-Anonymisierung). Antwort-Ansicht (externe Antwort einfügen, Live-Vorschau der Wiedereinsetzung, Originalwerte blau). Finalisierung (optionaler interner „Polish", dann `mailto:` „Re: <Betreff>" an Absender).
**Datenmodell dahinter:** `Anfrage`-Record: `absenderEmail`/`betreff`/`hatAnhaenge`, `originalMd` (editierbar), `anonymisiertMd`, `mapping[]` (Platzhalter↔Original, sensibelste Struktur, nie transportiert), `verallgemeinerungen[]`, `externeAntwortAnon`, `finaleAntwort`, `anonBasisHash` (Stale-Erkennung), `metadaten` (getaggt: `antragsart`/`name`/`firma`/`themengruppe` + `status` getaggt/ausstehend/fehlgeschlagen; `name`/`firma` Klartext-PII, nur lokal; Themengruppe = festes Vokabular). `PiiTyp`: person/firma/ort/fkz/email/telefon/iban/x500/hostname/sonstiges.
**Typische Aktionen:** .msg importieren (Tagging automatisch); in der Tabelle nach Art/Thema/Firma/Status filtern/sortieren; im Detail erneut taggen; Original bereinigen; anonymen Text prüfen/kopieren; externe Antwort einfügen; Wiedereinsetzung kontrollieren; finalisieren und versenden.
**Code:** `src/plugins/anfragen/` — `AnfragenPage.tsx`, `AnfrageTabelle.tsx` (Filter-Tabelle), `AnfrageMetadatenStrip.tsx`, `services/metadaten.ts` (Tagging, intern-only), `services/anrede.ts` (Export-Präambel), `services/anonymisierung.ts` (intern-only), `AnonymisierungView.tsx`, `AntwortView.tsx`, `services/finalisierung.ts` (kein LLM).
