# Chat
**Zweck:** Nutzer stellt Fragen an einen lokalen KI-Assistenten — z. B. zu Förderanträgen, Dokumenten oder allgemein — mit optionalem Zugriff auf die Dokumenten-Archiv-Suche (RAG).
**UI-Elemente & Begriffe:** Verlauf-Sidebar links (Konversationen, anheftbar), Conversation-Bereich mit Nachrichten-Thread + Composer (Eingabefeld, Senden/Stoppen), „+"-Werkzeuge-Menü (Verzeichnisse wählen, Archiv-Suche ein/aus), Quellen-Chips + nummerierte Inline-Zitate `[n]` in Antworten, aufklappbares Quellen-Panel (Slide-over) rechts, Daumen-hoch/-runter-Feedback pro Antwort, Datei-Anhänge (PDF/DOCX/MD/TXT), „Denkprozess"-Anzeige (Reasoning) bei aktiviertem Thinking.
**Datenmodell dahinter:** `ConversationMeta`/`ConversationFull` (Titel, FKZ-Verknüpfung, gepinnt) mit `ChatMessage[]` (Rolle, Content, Attachments, `sources: ChatSource[]`, Stats, Feedback); persistiert über `useChatStore` in IndexedDB.
**Typische Aktionen:** Nachricht senden, laufende Antwort stoppen, Antwort erneut generieren (regenerate) oder bei Fehler wiederholen (retry), Archiv-Suche (RAG) an/aus schalten und Verzeichnisse als Kontext auswählen, Quelle anklicken um Ausschnitt zu sehen, Konversation umbenennen/anheften/löschen.
**Code:** `plugins/chat/` — `ChatView.tsx` (Shell), `useChatController.ts` (Senden/Kontext/Transport-Fallback-Ladder: Streaming → Multi-Turn → Single-Turn), `store.ts` (Persistenz), `conversation-context.ts` (API-Message-Bau).
