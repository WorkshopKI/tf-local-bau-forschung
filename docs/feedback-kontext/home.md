# Home
**Zweck:** Startseite — persönliches Dashboard aus konfigurierbaren **Widgets** (seit v2.227): eigene offene Förderanträge, Antragseingang, Notizen, KI-Status.
**UI-Elemente & Begriffe:** Begrüßung mit „X offene Vorgänge …"; darunter zwei Spalten mit Widgets, jedes mit Kopfzeile (Chevron zum Ein-/Ausklappen — eingeklappt bleibt nur der Zähler sichtbar — plus Stift-Popover „Widget anpassen", Hinweis „nur lokal auf diesem Gerät"; bearbeiter-bezogene Widgets zeigen den Modus „Kürzel THU" vs. „Alle Bearbeiter"). Widgets (alles read-only + Navigation, die neuen Opt-in): **Weitermachen**, **Meine Anträge** (Liste, „+10 mehr", „Alle →", Rückstands-Balken), **Kanban** (Quelle Förderanträge ODER Feedback, farbige Lanes bunt/einfarbig, 1–2 Spalten, „+ N weitere →"), **Antragseingang**-Ampel (Schwellen einstellbar, Zeile öffnet gefilterte Liste), **AI-Assistent**, **Notizen** („nur lokal · nie im Snapshot"), **Feedback-Neuigkeiten** (Antworten/neue Tickets/Stimmen seit letztem Besuch, „Alles gelesen"), **Auslastung** (Ich- oder Team-Sicht: Quartals-Belegung + Altanträge; nur wo Auslastung aktiv), **QS-Freigaben offen** (Artefakt-Entwürfe ohne Freigabe → „Freigeben/Prüfen →"; gibt nie selbst frei), **Registry-Änderungen** (nur Kurator: jüngste Skill-/Regel-Änderungen). Reihenfolge/Sichtbarkeit über Einstellungen → „Widgets auf der Startseite". Außerdem: Programm-Übersichtskarten, optional „Neue Anträge für dich" (Selbsteintragung aus der Auslastung).
**Datenmodell dahinter:** Widget-Config gerätelokal (IDB-Key `home-widgets-config`, gespiegelt in PersonalEinstellungen — nie im Snapshot); Inhalte aggregiert aus `useAntraegeStore` über `dashboardAggregate.ts`/`kanbanLanes.ts`; Profil (`useProfile`, Bearbeiter-Kürzel), aktives Programm. Notizen nur in der IDB.
**Typische Aktionen:** Widgets ein-/ausklappen, per Stift anpassen (Kanban-Lanes/Farben, Ampel-Schwellen), auf einen Antrag oder eine Ampel-Zeile springen (→ gefilterte Förderanträge-Liste), Kanban-Karte öffnen, Notiz festhalten, KI verbinden, Selbsteintragungs-Vorschläge annehmen.
**Code:** `src/plugins/home/` — `HomePage.tsx` (Orchestrierung/States), `widgets/` (Katalog, Config-Store, `WidgetShell`, `HomeWidgetStack`, Kanban/Notizen, `WidgetQuickEdit`), `dashboardAggregate.ts`, Sektions-Widgets `MeineAntraegeSection.tsx`/`EingangAmpelCard.tsx`/`AiAssistantCard.tsx`/`WeitermachenSection.tsx`.
